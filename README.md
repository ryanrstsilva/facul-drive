Este é um projeto [Expo](https://expo.dev) criado com [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Introdução

A versão com o APK segue com alguma pendência. Vou tentar corrigir e substituir o link o mais rápido o possível. Para executar pelo aplicativo do Expo Go segue as instruções:

1. Faça o Download do arquivo Zip com o projeto e o extraia em uma pasta.

2. Abra a pasta no terminal e instale as dependências com:

   ```bash
   npm install
   ```

3. Cole o arquivo .env (compartilhei um .zip pelo Drive) na pasta da raiz do projeto.


4. Suba aplicação com:

   ```bash
   npx expo start
   ```

5. Com o aplicativo Expo Go, basta ler o QR Code que aparecerá no terminal para executar o projeto.
